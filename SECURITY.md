# Security policy

## Supported versions

Only the latest published version receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for an unpatched vulnerability. Contact GptGate through [gptgate.ai](https://gptgate.ai/) or the official support channel and include the affected version, reproduction steps, and impact. Do not include passwords, tokens, private chat content, or user-profile files.

GptGate RTL communicates with a loopback-only debugging endpoint created for the launched ChatGPT process. The project must not collect chat contents or transmit local diagnostic data.
